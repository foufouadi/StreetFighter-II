# Street Fighter II (simplified)

[Français](README.fr.md)

A simplified version of Street Fighter II, written in C# with MonoGame (OpenGL).
One arena, two fighters (Ryu and Chun-Li), two players on the same keyboard.

Student project (university computer science, year 2). Work in progress.

## Assets
This is a fan project, not affiliated with Capcom. Street Fighter and its characters, graphics and sounds belong to Capcom.

Where the resources come from:
- Music and sounds: https://downloads.khinsider.com/game-soundtracks/album/street-fighter-ii-the-definitive-soundtrack
- Sprites: https://spritedatabase.net/game/632 and https://www.spriters-resource.com/arcade/streetfighter2/
- Move data: https://wiki.supercombo.gg/w/Street_Fighter_2:_Champion_Edition

Non-commercial, educational use only.
